
## Overview
MathVenture is a web based mathematics games that aims to teach children(within the age of 1-8) about basic mathematical operations(addition, subtraction, division and multiplication)

### Features

Users are able to:

- Select between the 4 categories

- Play 5 levels per category

- See a different theme depending on the category picked

- Have a saved version of their highscore(in localStorage) for each level
